## 资料收集模板

`资料收集模板/2-4-2 客户清单填报模板.xlsx` —— 供公司填报，含填报说明、两家主体的客户清单表、客户重合度分析表。营业收入已按财务报表预填于各表第 3 行，占比与达标判定自动计算。版式从简：全表仅表头一种浅灰底色，不做输入区、公式区的颜色区分，需填与不需填在说明中以文字指明。

> 注：该文件的公式未经 LibreOffice 重算验证（本环境 LibreOffice 无法运行，连单条 SUM 公式的文件都无法在 480 秒内完成重算）。已改用独立方式验证：灌入测试数据后按公式语义逐条复算，空表与灌数两种状态下的占比、小计、达标判定、勾稽差额均与预期一致；全部公式仅使用 IF 与 SUM，无兼容性风险。
