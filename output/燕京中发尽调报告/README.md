### 两方案比较（报告表格摘要）

| 比较维度 | 方案一：股权收购 | 方案二：资产收购 |
|---|---|---|
| 交易标的 | 燕京啤酒（邢台）全部股权 | 宗地一至三及地上建筑物，215.50 亩 |
| 土地增值税 | 不征 | 四级超率累进 30%~60%；以作价入股实施的可争取暂不征 |
| 增值税及附加 | 不征 | 按资产、负债及劳动力一并转让操作可争取不征 |
| 契税 | 不征 | 3%~5%；能否适用改制重组免税需与税务机关确认 |
| 企业所得税 | 符合条件可递延，预计 0 | 股权支付可争取递延；现金支付按 25% |
| 宗地四（集体地） | 随股权一并纳入 | 无法受让，需另行协议安排 |
| 旧证换发 | 不涉及 | 宗地一、二需先换证 |
| 历史负债及沿革 | 概括承受，沿革纳入核查 | 不承接 |
| 后续整合 | 需更名、变更经营范围及资质，并吸收合并 | 不涉及 |

**本轮补正了资产收购路径的税费口径**。上一版为衬托股权收购，把资产收购写得偏简单。实际上资产收购也有可争取的优惠，已据实补入：
- **增值税**：国家税务总局公告 2011 年第 13 号、财税〔2016〕36 号附件 2——资产重组中将实物资产连同相关联的债权、负债和劳动力一并转让的，涉及的不动产、土地使用权转让不征增值税
- **土地增值税**：财税〔2018〕57 号及其后续延续文件——改制重组时以房地产作价入股投资的暂不征；本案双方均非房地产开发企业，不落入除外情形
- **契税**：同一投资主体内部划转免征，但发行人并非燕京啤酒全资子公司，是否落入该口径**存疑，不下断言**，写明需与主管税务机关确认

结论相应调整为：**并非税负天壤之别，而是股权收购的确定性更高，资产收购需逐项争取、取决于交易结构与税务机关意见。**

### 方案选择的考虑因素（（3）④）

**取决于尽调结果**：标的公司或有负债与税务环保遗留；其两年一期财务状况（决定作价与稀释幅度）；土地评估增值幅度（增值有限则资产收购税负劣势缩小）；113 名员工的劳动关系归属；宗地四实际使用状况。

**取决于公司诉求**：对承接标的公司 2005 年以来历史沿革的接受程度；对重组周期的要求；对价支付方式安排；燕京啤酒对保留该主体的意愿；员工安置意向。
