## 重组交易涉及两个层面的股权变化

这是本方案最容易读混的地方，报告中已分层写明：

| 层面 | 交易前 | 交易后 |
|---|---|---|
| **中发邢台** 的股东 | 燕京啤酒 67%、燕京中发（发行人）33% | 燕京中发 **100%** |
| **燕京中发（发行人）** 的股东 | 燕京啤酒 80%、燕京集团 17.5%、食品发酵研究院 2.5% | 燕京啤酒 **84.35%**、燕京集团 13.69%、食品发酵研究院 1.96% |

发行人自身股东结构之所以变动，是因为**收购对价不是现金，而是发行人向燕京啤酒定向增发自身股权**：燕京啤酒交出中发邢台 67% 股权，换回发行人新增的 1,112.67 万元出资额，发行人注册资本由 4,000.00 万元增至 5,112.67 万元。燕京集团与食品发酵研究院未参与本次出资，持股比例被动稀释；控股股东及实际控制人未变。

报告中的股权结构表为**发行人自身**的股权结构，表头已标注"发行人股东名称"，表下注同时给出中发邢台的股权变化。

## 土地方案：收购标的公司 100% 股权

**新掌握的事实**：燕京啤酒（邢台）有限公司的厂区已整体转为纳豆及纳豆制品生产，不再从事啤酒业务，公司主体仍存续。即"地和厂房在这家公司名下，跑的却是发行人体系的纳豆业务"。

据此，（3）解决方案**直接写股权收购一条路径**，不作方案比较：由发行人以自身股权为对价，收购燕京啤酒持有的燕京啤酒（邢台）有限公司 100% 股权。选择该路径的理由在引言中以一句话交代（直接购入土地会触发土地增值税、增值税及附加与契税，且宗地四无法一并受让），不再单列资产收购方案。

（3）结构：①交易方案及交易后架构 → ②税费测算（表）→ ③配套事项（四项）→ ④尽职调查及风险控制 → ⑤实施步骤及过渡期安排。

**税费测算表**（单方案，列示政策依据、适用性与税务成本）：

| 税种 | 适用性 | 税务成本 |
|---|---|---|
| 土地增值税 | 标的为股权，标的公司仍为权利人，权属未转移 | **不征** |
| 增值税及附加 | 转让非上市公司股权不属于征税范围 | **不征** |
| 契税 | 不涉及土地、房屋权属转移 | **不征** |
| 企业所得税 | 收购比例及股权支付比例均 100%，高于财税〔2009〕59 号的 50%、85% 门槛 | 特殊性税务处理下**预计为 0** |
| 印花税 | 产权转移书据，万分之五，双方分别缴纳 | 按作价测算 |
| **合计** | | **预计仅产生印花税** |

方案设计参考靖江亚泰方案二的逻辑（母公司剥离业务→上市主体股权收购→原主体转型、注销资质），但本案更简单：厂区已完成生产转换，标的公司本身即为"装着土地厂房、跑着纳豆生产"的干净标的，**无需先行分立**。

**四项配套事项**（（3）③）：
1. **更名**，去除"燕京啤酒"字样——该名称系控股股东字号，保留会形成品牌混同，且与变更后的纳豆主业不符
2. **变更经营范围、注销啤酒生产许可**——否则发行人将持有一家啤酒制造企业，**与控股股东形成新的同业竞争**
3. **两家邢台主体择机吸收合并**，实现房、地权属统一
4. 与中发邢台股权重组**统筹**——两次交易均以发行人股权支付，会连续提升燕京啤酒持股、连续稀释其余股东

**两项风险**（（3）④）：股权收购系概括承受（或有负债、担保、诉讼、啤酒生产期间的税务与环保遗留、113 名员工安置）；以及"以转让股权名义转让土地"被追征土地增值税的实务风险，已给出三条抗辩基础并建议事先与税务机关书面沟通。
