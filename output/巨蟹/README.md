# 巨蟹智能尽调报告 第六章 公司所处行业分析

无锡巨蟹智能驱动科技有限公司，机器人一体化关节模组及谐波减速机等核心零部件。
交付物为单独一章的 Word 文档，版式复刻《国泰海通关于巨蟹智能之尽职调查报告V7.docx》。

## 文件

| 文件 | 说明 |
|---|---|
| `巨蟹智能尽调报告第六章_公司所处行业分析.docx` | 交付物，13 页 |
| `fmt.py` | 版式外壳：读模板取页面设置与页眉页脚，提供标题、正文、资料来源、表格、插图五种构件 |
| `charts.py` | 三张配图 |
| `ch6.py` | 正文内容，运行它生成交付物 |

## 运行

```bash
python3 charts.py && python3 ch6.py
```

`fmt.py` 需要模板文件 `../v7.docx`。**模板与领导批注不入库**，放在临时目录，
用完即弃；招股说明书、券商研究报告等外部资料同样不入库。

## 章节结构

按模板原有的四节骨架，未新增大板块。

- （一）所属行业
- （二）行业主管部门、监管体制、主要法律法规及政策 —— 行业标准、法律法规、产业政策三张表
- （三）行业发展情况 —— 一体化关节模组、谐波减速机、下游人形机器人、其他应用领域、发展趋势
- （四）行业竞争情况 —— 竞争格局、主要竞争对手、行业壁垒与主要竞争要素

## 版式参数（实测自模板）

- A4 纵向 11906×16838 twips，上下边距 1440、左右 1800，版心宽 8306
- 一级标题「六、」黑体 14pt，行距 1.5，段前段后各 6pt，无首行缩进
- 二三级标题宋体加粗 12pt，首行缩进 2 字符，段前 6pt
- 正文宋体 12pt、西文 Times New Roman，首行缩进 2 字符，行距 1.5，段前 6pt，两端对齐
- 资料来源 10.5pt，无缩进
- 表格宽度 100%、fixed 布局，外框 sz=12、内线 sz=4，首行加粗居中并设 tblHeader
