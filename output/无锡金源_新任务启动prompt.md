# 新任务启动指令：无锡金源专题材料

> 使用方法：把本文件全文粘贴到新对话的第一条消息，再附上你手上的材料。

---

## 一、任务

根据我提供的报告和公开资料，梳理汇总**无锡金源**的以下四个板块：

1. 市场竞争
2. 发展趋势
3. 客户开拓
4. 核心技术

**不做整份报告**，只把这四个板块摘出来单独成文。

**交付定位**：先给领导看，后续用于向企业汇报。因此以事实为底、取积极面；不做欺骗，但不利判断不主动展开。

**体例**：参照投行尽职调查报告，即 A 股招股说明书的行文体例。

---

## 二、最要紧的一条：分清行业层面与公司层面

四个板块分属两个层面，写作时不得互相串味：

| 板块 | 层面 | 该回答什么 |
|---|---|---|
| 市场竞争 | **行业** | 竞争格局、主要竞争对手、进入壁垒、公司在行业中所处的位置 |
| 发展趋势 | **行业** | 技术、需求、竞争维度、国产化等方向性变化 |
| 客户开拓 | **公司** | 客户结构、认证与导入路径、开拓进展 |
| 核心技术 | **公司** | 技术构成、来源、产业化程度 |

**判断标准**：写「市场竞争」和「发展趋势」时，主语是行业和环节，不是公司；公司只在"处于什么位置"时出现。写「客户开拓」和「核心技术」时才以公司为主语。

反面案例（我在上一个项目犯过）：在行业章节的"公司竞争地位"里写了研制基地面积、专利件数、资质认定、获奖、融资轮次——这些回答的是"这家公司是谁"，不是"它在行业里处在哪"，应当全部移出。

## 三、工作流

### 1. 先理解，再动笔
- 收到材料后，先读、先问，**不要直接开始写**
- 有不确定的地方就问我，**问到有九成把握再动笔**
- 需要加入的内容，先向我确认

### 2. 先出方案，再执行
- 大的结构调整、新增章节、新增图表，先给方案让我看，我确认后再做
- 方案要写清：内容、来源、篇幅、加它的理由、风险

### 3. 边干边问
- 我随时在。遇到判断题就问，不要自己猜
- 遇到两个数据打架、口径对不上，**必须停下来问**，不要自作主张选一个

### 4. 每轮交付
- 改完跑一遍机器自查（见第六节）
- 说清楚改了什么、为什么改、哪里没改
- 有推翻自己上一轮判断的，直说，不要含糊过去

## 四、写作风格

### 边界
- **每节只答本节该答的问题**。放错位置就是废话，哪怕内容本身是对的
- 上文写过的，下文不再写；反之亦然
- 不拆自己的主营业务讲，主营业务一句带过，产品名平铺，不解释

### 句子
- **能概括的不枚举**。「A、B、C、D 四类部件」→「A 等核心零部件」
- **删填充句**。换到任何同类对象上都成立的句子（如"直接决定性能、可靠性和使用寿命"），删掉不损失信息
- 一句一个意思，长难句拆开；分号并列、顿号清单不算长难句
- **结论先行**，事实前置、判断收尾
- **不用自述视角**——不写"本报告认为""我们判断"
- **不做交叉引用**——不写"如前所述""前述""见表 X""见本章某节"
- 陈述句为主，不堆形容词；"快速增长"可以，"迅猛爆发式增长"不行
- 数字紧跟单位和年份；术语首次出现给中文全称；全角标点

### 篇幅
- 单节 200–350 字、一到两段是常态
- **不凑字数**——凑字数必然产生上面两类废话

### 两句自查
> 这句话该不该放在这一节？
> 删掉会不会损失信息？
>
> 两问过不了的，删。

## 五、来源规则

### 引什么
- 一手机构名：灼识、沙利文、IDC、Omdia、GGII、中国电子学会、中国信通院等
- 上市公司公开披露（年报、招股说明书、公告）
- 政府文件、国家标准
- 公司官网、产品手册、专利等公司自身公开原件

### 不引什么
- **公众号文章一律不引**，只引它转述的一手机构
- **券商研报不直接引**。研报里的数据要引它的原始来源；研报自己的观点，用我们自己的话表达
- 我自己整理的材料**可信度低、优先级低**，只作线索，以公开原件为准

### 怎么引
- **数据引机构，观点用自己的话。** 机构名不该出现在观点前面
  - 错：「根据 X 咨询的研究，本行业壁垒包括……」（观点）
  - 对：「本行业属于……。据 X 咨询统计，2025 年市场规模为 Y 亿元。」（数据）
- 来源单独成行跟在图表下方，正文不写"某某招股说明书显示"
- 引用第三方数据须注明来源与时效（《公开发行证券的公司信息披露内容与格式准则第 57 号》第九条）

### 口径纪律（血的教训）
- **每个细分市场只用一套主口径**，不要把两家机构的同类数据并排放
- 确需并列时，**每个数字自带定语**（年份、地域、统计范围），让标签本身说明口径
- **不要写"二者口径不同、不具可比性"这类说明句**——那是免责声明，不是分析。审慎应体现在把话说准，不是在句子后面挂免责尾巴
- 引用别人的数据前，先做一次**内部验算**（分子分母是否同源、加总是否对得上、隐含单价是否合理）

## 六、不要错进错出

这是最高优先级的一条。

- 所有数字、名称、日期，**以公开原件为准**，不以二手转述为准
- 拿不到原件的，**宁可不写，也不写一个"大概是这样"的数**
- **拿不到的数据就不写，不留空、不标"待补"**
- 发现自己写错了，直接说、直接改，不找补
- 特别小心这几类错误（都是我踩过的）：
  - 把申请量写成授权量
  - 把成本写成售价
  - 把产量写成出货量
  - 拿大规格产品的单价去代表整个品类
  - 把某家头部企业的个案当成行业平均
  - 从"占 30%–50%"推出"占比最高"这类外推

## 七、自查清单（每轮改完跑一遍）

机器可查：

- [ ] 重复片段（≥12 字的句段重复出现）
- [ ] 交叉引用：如前所述／前述／见表 X／见图 X
- [ ] 自述视角：本报告认为／我们判断
- [ ] 正文来源引述：据其披露／某某招股说明书显示
- [ ] 叠字错字：的的／已已／和和
- [ ] 半角标点、中文数字量词
- [ ] 超长段落（>300 字）
- [ ] 图表编号连续性

人工要看：

- [ ] 每一节是否只答了本节该答的问题
- [ ] 同一数字在不同小节是否一致
- [ ] 同类数据是否存在口径冲突
- [ ] 有没有可以删掉而不损失信息的句子

## 九、保密约束

- **客户非公开信息与商业秘密禁止写入交付物**：客户名称、单价、销量、收入占比、前五大客户构成等
- 需要用到这类信息时，只能作为**判断依据**（例如决定各板块的篇幅分配），不进正文
- 内部投资关系、投后材料一律不得用于给企业看的材料
- 参考用的外部招股书、研报、模板不入库，只放临时目录
