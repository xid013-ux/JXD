# 案例：无锡金源半导体（2026-08）

这个案例是本 skill 的来源。记录**当时怎么走弯路的**，比记录结论有用。

## 走过的弯路

| 弯路 | 后果 | 正确做法 |
|---|---|---|
| 先按"半导体设备零部件与耗材"整体铺开写 | 市场空间、竞争格局都说不清，写了一堆没落点的内容 | 先拆到匀气盘/加热盘/O型圈三个单品，再定框架 |
| 材料路线一直挂着"金属/非金属两条都列" | 表格双写、正文摇摆，后面一路要打补丁 | 阶段二就该用官网型号把路线定死 |
| 把只适用于"碳化硅"的结论用到"含硅、金属、碳化硅"全品类上 | 写出"国内尚无稳定量产企业"，被领导当场指出错误 | 引用任何"国产化率""无量产"的说法，先确认它限定的是哪一种材质 |
| 四条产品线平均用力 | 篇幅浪费在门板和O型圈上，主力反而没写透 | 阶段二就分主次 |

## 拆解链条（可复用）

```
官网型号 LAM AHM / STRATA / Q-STRATA 300mm
  → 查得三者同属泛林 VECTOR 系列
  → VECTOR 是 PECVD/PEALD 薄膜沉积平台，不是刻蚀平台
  → 硅/碳化硅气体分配盘主要用于刻蚀 ⇒ 排除非金属路线
  ＋ 媒体报道用词"金属喷头"
  ＋ 经营范围有"金属制品研发与制造"、无半导体材料加工
  ⇒ 判定：铝合金＋表面处理的金属件，配薄膜沉积机台
  ⇒ 连带结论：最贴切的可比公司是先锋精科（同为金属件、同在薄膜沉积供匀气盘与加热器）
```

一条线索不够，三条指向一致才下判断。

## 三条产品线的瓶颈定位

| 产品 | 细分品类 | 瓶颈段 | 依据 |
|---|---|---|---|
| 气体喷头 | 金属匀气盘（薄膜沉积用） | 加工工艺端 | 铝材供应充分，差距在阳极氧化、熔射涂层 |
| 加热盘 | 氮化铝陶瓷加热器 | 原材料端（正在缓解） | 珂玛披露氮化铝原粉境外采购占比 91.86%→80.70%→29.33% |
| O型圈 | 半导体级FFKM密封圈 | **原材料端** | 加工不难，难在胶料配方与验证；芯密科技毛利率 58.70%→65.54% 反证门槛在料不在成型 |

## 好用的信源

| 信源 | 能拿到什么 |
|---|---|
| 同品类**在审/已上市公司的招股说明书** | 第三方机构数据（弗若斯特沙利文、QY Research、CIC）、可比公司毛利率表、技术难点分类 |
| **问询回复**（尤其第二轮及以后） | 竞争对手的分产品收入/销量/单价/毛利率，常比招股书正文更细 |
| **投资方是上市公司时的公告** | 标的的客户名单、量产状态 |
| 交易所网站、证监局辅导备案 | 券商在手项目、可比项目 |

问询回复里常藏着别人家的数据：无锡金源的 O型圈可比对象芯密科技，就是在臻宝科技第二轮问询回复里找到的。
