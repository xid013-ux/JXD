# 报告结构

## 标题层级

只用两级，不要三级：

- **一级**：`一、二、三、……`（Heading 2 样式，Word 自动编号，写标题文字即可）
- **二级**：`1.1 / 1.2 / 2.1 ……`（Heading 3 样式，编号手写进标题文字里，
  样式里的自动编号已被抑制）

目录用 Word 域（`TOC \o "1-3" \h \z \u`）生成，一级顶格、二级缩进，
右对齐页码带点线导引，页码由 `PAGEREF` 域取，打开文档时自动刷新。

---

## 先定章节：按标的性质选，不套固定骨架

**没有一套骨架适用于所有标的。** 章节安排在框架阶段就定下来，写进给用户确认的
那一页框架里，确认后再动笔。

### 三种典型组合

| 场合 | 结构主线 | 参考 |
|---|---|---|
| **A 产业链／赛道研究** | 行业先行：行业→产业链→规模→格局→企业→资本化 | 见下方"九章骨架"，人形机器人报告即此结构 |
| **B 标的公司研究／拜访前** | 公司先行：公司产品→所处环节→上下游→细分市场→可比公司→拜访要点 | 见下方"公司先行结构"，无锡金源报告即此结构 |
| **C 早期项目初判** | 只要 B 的前半段：公司产品→细分品类→可比对象→关注要点 | 5–8 页量级 |

### 怎么选

- 题目问的是**行业**（"这个赛道怎么样"）→ A
- 题目问的是**一家公司**（"研究一下这家、顺带看它的产业"）→ B
- 只是**初步判断要不要往下推** → C

### 可选章节（按需加，不是标配）

| 章节 | 什么时候加 |
|---|---|
| IPO 审核关注要点 | 标的有资本化预期、且要体现投行价值时。**每次开工问一句**，不默认写 |
| 与本机构相关的产业链公司 | 需要展示可赋能资源时 |
| 资本化进度盘点 | 题目就是资本化，或需要看赛道整体拥挤度时 |
| 代表性企业逐家展开 | A 结构里通常要；B 结构里由"可比公司"一章替代 |

**加了哪些、不加哪些，都要在框架里写明原因。**

## 九章骨架（A：产业链研究）

领导定稿的产业链研究结构，做赛道研究时沿用，按题目增删小节。

### 一、XX 产业概述
- 1.1 行业简介
- 1.2 主要产品形态与技术路线
- 1.3 基本构成（挑一个最能说明问题的部件展开，作为后文的锚点）
- 1.4 行业的基本指标（怎么衡量这个行业：出货量、装机量、单价、国产化率等）

**作用**：让不懂这个行业的读者在两页内建立基本图景。不做判断。

### 二、产业链结构及各环节比较
- 2.1 产业链整体结构与价值传导（配 BOM 成本拆分图）
- 2.2 上游核心环节（一）
- 2.3 上游核心环节（二）
- 2.4 上游核心环节（三）
- 2.5 上游其他环节
- 2.6 中游：整机制造
- 2.7 下游：应用场景与集成服务

**篇幅分配**：与研究目的相关的环节写透（技术门槛、工艺难点、竞争格局、
国产化进度、代表企业、价格与毛利），不相关的环节一段带过。
**不相关不等于不写** —— 产业链要完整，只是深浅不同。

### 三、国内市场发展现状及产业规模
- 3.1 出货量与市场规模
- 3.2 应用结构（下游场景占比）
- 3.3 招投标与订单
- 3.4 成本曲线与降价趋势
- 3.5 相关政策
- 3.6 区域产业集群（如果和标的所在地相关，单列一小节）

### 四、行业格局、发展趋势及产业机会
- 4.1 整机环节竞争格局
- 4.2 核心环节竞争格局
- 4.3 产业链价值迁移与业务机会

**注意**：这是全篇唯一允许带方向性判断的行业章节，但仍要事实先行、
判断压在段内，不单独成节。

### 五、整机制造环节代表性企业
每家一个小节，按重要性排序，最后一节收"第二梯队与新兴企业"，
再加一节"海外对照"。

单家公司的展开维度（重要的公司才全展开）：
1. 公司概况与沿革
2. 创始团队与核心高管（**用表格**：姓名 / 职务 / 教育·职业背景）
3. 组织架构与管理机制
4. 产品线（**用表格**：产品 / 定位 / 关键参数 / 状态 / 价格）
5. 技术与软件栈
6. 供应链体系
7. 出货与商业化进展
8. 资本化情况（轮次、投资方、上市进度；**不展开发行参数**）

### 六、产业链企业资本化进度
- 6.1 已上市或已进入发行阶段的企业
- 6.2 已上市的产业链相关公司一览（按环节）
- 6.3 在审、已受理或已递表的企业
- 6.4 辅导备案或已完成股改的企业
- 6.5 通过上市公司平台实现资本化的企业
- 6.6 IPO 终止或撤回的企业

⚠️ **不写 6.7 小结**。领导删过。

表格必备列：公司名称 / **主营业务情况** / 所属环节 / 上市地或进度 /
中介机构（保荐、辅导券商）/ 时间 / 数据来源。
"主营业务情况"是领导后加的要求，一句话说清做什么，真实可查即可，不要长。

### 七、与本机构相关的产业链公司
- 7.1 已保荐上市的公司
- 7.2 正在保荐、在审或辅导中的公司
- 7.3 曾保荐但已终止的公司
- 7.4 股权投资与产业基金
- 7.5 关联全景与小结

**纪律**：股权投资和保荐关系严格分表；合并前的国泰君安、海通证券项目要包含在内，
按当时主体名称列示；间接持股要写明穿透路径和"穿透比例未披露"这类客观事实。

### 八、标的公司的产业链定位与拜访关注要点
- 8.1 公司概况与产品体系
- 8.2 产业链定位与可比公司
- 8.3 拜访关注要点
- 8.4 初步判断

**这一章是内部视角的唯一容身处**。前七章保持中性，所有"我们该关注什么""
可能的机会点"集中写在这里。

### 九、主要数据来源与口径说明

**简要写**。就说用了哪几类数据、采用什么口径、截止到什么时间。
不要展开成方法论论文，不要写免责声明，半页到一页足够。

## 公司先行结构（B：标的公司研究）

无锡金源报告的实际结构，做拜访前研究、标的尽调时沿用。
**特点是从公司的产品出发，一路推到行业，而不是先铺行业再落到公司。**

### 一、标的公司与产品
- 1.1 公司概况（工商、资质、融资）
- 1.2 产品体系与对应的材料及工艺（**核心表**：每条产品线的材料、技术路线、工艺）

产品线的**技术路线判断**放在这一章，并列出判断依据。路线定不下来，
后面所有对标都会摇摆。

### 二、所处环节与产品属性
- 2.1 环节定位与分类（把产品归进行业的标准分类）
- 2.2 耗材属性 / 更换周期 / 收入形态

### 三、上游材料与中游制造
- 3.1 上游：**按产品逐条写**"这条线用什么料、这个料的格局与国产化程度"
- 3.2 中游：制造工艺与标的的生态位
- 3.3 下游：客户结构

### 四、细分市场与国产化进度
- 4.1 所处环节的整体规模
- 4.2 **与标的产品一一对应的细分品类**（规模、竞争格局）
- 4.3 国产化现状、难点与增长空间

⚠️ 引用"国产化率""无稳定量产企业"这类说法时，**先确认原文限定的是哪一种材质／
哪一个细分**。金源那次把只适用于碳化硅的结论套到全品类上，被当场指出。

### 五、可比公司
- 5.1 可比范围与选取标准
- 5.2 毛利率对比（按材料路线或技术路线分组）
- 5.3 **分产品毛利率**——与标的产品直接对应的那几个品类
- 5.4 研发投入

**可比公司数量不设硬上限。** 原则是"精挑几家，核心是跟标的产品最相似的"，
够说明问题就行，不铺开。选取标准要写出来。

### 六、（可选）IPO 审核关注要点

### 七、（可选）与本机构相关的产业链公司

### 八、拜访关注要点
一张表：关注维度 / 具体问题 / 提问依据。**提问依据要落到前文的具体数据上。**

### 九、口径说明
半页。只写几处需要注意的口径差异，不写方法论。

## 图表配置参考

**按结构定，不套同一个数。** 两种结构的实测值：

| 结构 | 篇幅 | 表 | 图 | 说明 |
|---|---|---|---|---|
| A 产业链研究 | 约 25,000 字 | 17–18 | 8 | 要讲清行业全貌，图用来看趋势和结构 |
| B 标的公司研究 | 约 19,000 字 / 25 页 | 16 | 4 | 金源实测。表远多于图 |

**B 结构表多图少是对的，不是缺图。** 这类报告的主体是对照——产品对材料、
产品对细分品类、可比公司对毛利率——**对照关系用表比用图清楚**。
图只在两种情况下做：一是同一指标跨年份的变化（毛利率三年走势），
二是量级悬殊需要一眼看出来的（各公司问询问题数）。

图的典型题材：
- BOM 成本结构拆分（饼图或堆叠条）
- 关键零部件国产化份额与集中度（堆叠柱 + 折线）
- 代表企业对比（分组柱）
- 下游应用场景结构（饼图）
- 出货量与增速（柱 + 折线双轴）
- 招投标金额趋势（柱）
- 全球竞争份额（饼或堆叠）
- 代表企业产能爬坡（折线）

**每张图都必须能被正文的一句话概括**。图说明不了事的就不做图，用表。

**图的可读性有硬约束**：五条以上折线、带缺口的序列，一律改分组柱状图。
金源那次的"问询轮次收敛"图，五家公司三条有缺口，折线怎么调标签都在打架，
换成分组柱当场就清楚了。
