## 表格

| 项 | 值 |
|---|---|
| 表宽 | `w:tblW w=5352 type=pct` |
| 表对齐 | 居中（`tblPr` 和每个 `trPr` 都要设 `w:jc=center`） |
| 外框线 | `single`，`sz=12`（1.5pt），色 `010000` |
| 内框线 | `single`，`sz=4`（0.5pt），色 `010000` |
| 列宽 | `tcW` 用 `pct`，按传入权重归一化到 5000 |
| 表头行 | 加粗居中；`trPr` 加 `cantSplit` + `tblHeader`（跨页重复表头） |
| 数据行 | `trPr` 加 `cantSplit`；单元格 `vAlign=center` |
| 单元格水平对齐 | 短字段居中，长文字段左对齐（`aligns` 参数逐列指定） |
| 换行 | 单元格文本里用 `\n`，会拆成多个段落 |

表标题在表**上方**，居中加粗；数据来源注在表**下方**，七号居中。
表标题段落要加 `keepNext`，避免标题和表分页分离。

### ⚠️ 表图标题的编号与题名之间用空格，不用冒号

```
✅  表1  人形机器人主要产品形态与技术路线
✅  图2  谐波减速器：国产份额与市场集中度（GGII口径）
❌  表1：人形机器人主要产品形态与技术路线
```

领导定稿版 25 个表图标题**全部**用空格分隔，无一例外。
题名内部可以用冒号（如"图2 谐波减速器：国产份额与市场集中度"），
但编号与题名之间只用空格。

## 目录

用 Word 的 TOC 域，不要手打目录：

- 域代码 `TOC \o "1-3" \h \z \u`
- 每个标题处插 `bookmarkStart/End`，命名 `_Toc90XXXX`
- 目录项用 `hyperlink w:anchor` + `PAGEREF <bookmark> \h` 域
- 制表位：右对齐、点线导引、`w:pos=8299`
- 整块包在 `w:sdt`（`docPartGallery = Table of Contents`）里
- `settings.xml` 设 `<w:updateFields w:val="true"/>`，Word/WPS 打开时自动刷新页码

`_helpers.py` 的 `make_toc(doc)` 已实现全部上述结构，并会先做一次粗略页码估算
填进去（Word 打开后会刷新为准确值）。

⚠️ `w:updateFields` 必须插在 `hdrShapeDefaults`/`footnotePr`/`compat`/`rsids` 等
元素**之前**，否则 `settings.xml` 违反 CT_Settings 顺序，文件打不开。

## OOXML 顺序陷阱

这是本项目踩过最多次的坑：**OOXML 的 `pPr`/`tblPr`/`tcPr`/`trPr` 子元素顺序由 XSD 强制**，
python-docx 的 `append()` 按调用顺序放，很容易违规。

解决办法：所有构建完成后 `import _fixup`，它会遍历全文对四类容器按标准顺序重排，
然后保存。**必须是最后一步。**

校验：

```bash
python3 /mnt/skills/public/docx/scripts/office/validate.py 报告.docx
```

## 中文排版细节

- 引号一律全角 `“”`；`_helpers.py` 的 `_q()` 会把 ASCII `"` 成对转成弯引号，
  所有 `add_run` 都过这个函数
- 数字和单位之间不加空格：`2万台`、`150.80元/股`
- 中英文之间不手动加空格（模板不加）
- 破折号用 `——`（两个全角）
- 省略号用 `……`
- 括号：中文语境用全角 `（）`，纯英文/数字内容用半角
