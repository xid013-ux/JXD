# 数据与来源规范

**每一个观点、每一个数字都必须有出处。** 这条没有例外。

取数的方法论（四步法、双出处、口径拆解）见 `AI作业方法.md`，
本文件是它在写作环节的落地规则。

---

## 〇、双出处要求

> **同一指标至少保留两个维度：原始出处 + 转述出处。**

- **原始出处**：数据最初的发布方 —— 统计局、行业协会、公司年报、招股书、交易所公告
- **转述出处**：引用它的地方 —— Wind、券商研报、媒体报道

来源注里两个都写，原始在前、转述在后：

```
数据来源：中国汽车工业协会《2025年汽车工业经济运行情况》；Wind整理成果，本报告整理。
```

只有转述出处、追不到原始出处的数据 → 谨慎使用，能不用则不用。
连转述出处都说不清的 → 不用。

---

## 一、来源标注的写法

放在表格/图的正下方，七号字居中。**结构是"出处 + 口径说明"两段：**

```
数据来源：<出处1>；<出处2>；<出处3>。<口径、边界与本轮修订说明>
```

领导定稿版的实际写法（25 条，平均 108 字）：

> 数据来源：高工机器人（GGII）《全球谐波减速器市场"沉浮录"》，2025年6月11日。
> 左图为国产厂商在谐波减速器市场的份额，右图为全球工业机器人用谐波减速器TOP4厂商
> 合计份额，两者统计边界不同。

> 数据来源：Wind整理成果；中国证监会及各地证监局辅导备案公示；港交所披露文件；
> 公开融资报道及企业工商信息。"券商系股东或投资方"一栏系通过股东穿透与融资报道整理，
> 仅反映券商与企业已有股权层面的接触，不代表已建立保荐或辅导关系，两者不可相互推定。

### ⚠️ 三条硬要求

**① 署名用「本报告整理」，不要写"国泰海通投资银行部整理"**

领导定稿版 25 条来源注中，"本报告整理"出现 9 次，
"国泰海通投资银行部整理"出现 **0 次**。
文中出现"国泰海通"的两处，都是作为**内容**（说明主体沿革），不是署名。

**② 多个出处之间用分号「；」分隔**，不用逗号。从原始出处到转述出处排序。

**③ 出处后面要跟口径说明**，不能只写来源就完了。说明的内容包括：
- 本表/本图覆盖的范围与截止时点
- 统计边界差异（"两者统计边界不同"）
- 不可推定的关系（"不代表已建立保荐或辅导关系，两者不可相互推定"）
- 不宜做的运算（"各只基金的规模不宜简单加总"）
- 完整性边界（"本表不构成完整清单"）
- 本轮修订留痕（"本报告复核后补充XX、XX三家"）

这些不是免责声明，是**口径交代**。区别在于：免责声明是推卸责任，
口径交代是告诉读者这个数能怎么用、不能怎么用。

### 引用具体报告时要写全

机构简称 + 全称 + 报告全名 + 发布日期：

```
高工机器人（GGII）《全球谐波减速器市场"沉浮录"》，2025年6月11日
新战略咨询与人形机器人场景应用联盟《2025—2026年度人形机器人产业发展研究报告》，
2026年3月30日发布
```

**"数据来源"用于数值类，"资料来源"用于文字/事实类。** 两者都用七号居中。

### 固定用词（不要改写）

| 场景 | 写法 |
|---|---|
| Wind 取数 | **Wind 整理成果** / Wind 金融数据库整理成果 |
| 署名 | **本报告整理** |
| 多来源分隔 | 分号「；」 |

正文中引用具体数据时，机构名和报告名要出现在句子里，
不能只靠表下的来源注：
"根据新战略咨询与人形机器人场景应用联盟的统计，2025 年国内出货约 2 万台。"

## 二、口径纪律（最容易出错的地方）

### 不同口径并列，绝不平均、绝不合并

同一个指标不同机构给出不同数字是常态。**三个口径就写三个**：

> 2025 年国内人形机器人出货量，新战略咨询与人形机器人场景应用联盟口径约 2 万台，
> GGII 口径约 1.8 万台，赛迪顾问口径全球约 1.7 万台、中国约 1.44 万台。
> 差异主要来自对整机的定义范围（是否含轮式底盘、是否含科研样机）。

禁止：取平均、取中位、"约 1.8–2 万台"这种模糊合并、只选对自己论点有利的那个。

**冲突数据必须解释口径差异**。不是选一个，也不是取平均，
而是说清楚为什么不一样（定义范围、统计方法、时点不同）。

### 每个数字必须三要素齐全

**年份 + 单位 + 口径**。缺一个就是不合格的数据。

- ❌ "谐波减速器国产份额约 40%"
- ✅ "2025 年国内人形机器人用谐波减速器，按出货台数口径国产份额约 40%"

### 写数之前先拆四组维度

任何一个指标名词都能再拆。写之前先答这四行，答不上来就是没查清：

| 维度 | 取值示例 |
|---|---|
| 统计对象 | 产量 / 销量 / 装机量 / 出货量 / 营收 |
| 地域 | 国内 / 出口 / 全球 |
| 品类 | 乘用车 / 商用车；整机 / 部件；工业级 / 消费级 |
| 时间 | 全年 / 累计 / 单季 / 单月 |

### 不要跨年份、跨口径做比较

份额、增速、排名这类指标，比较的两个数必须同源同口径同年。
不同来源的数放在一起只能并列陈述，不能相减、相除得出结论。

⚠️ **不同口径体系之间不做乘除推导**。例：
"2025 年中国新能源汽车销量约 1649 万辆"与"全球 EV 电池装车约 1187GWh"
分属不同统计对象和不同地域，相除得出的"单车带电量"是错的。

## 三、取数优先级

1. **一手公开披露**：招股说明书、年报、半年报、公告、交易所问询回复
2. **官方与协会**：工信部、地方经信委、中国机器人产业联盟、行业联盟统计
3. **权威第三方**：Wind、GGII、赛迪顾问、新战略咨询、IDC 等（注明机构名）
4. **公司官方口径**：官网、发布会、官方公众号、高管公开访谈
5. **媒体报道**：只在 1–4 都没有时使用，且必须是主流财经媒体，注明媒体和日期

⚠️ **不用**：自媒体、雪球/知乎个人帖、来源不明的行业群传闻、
无署名的"某券商研报截图"。

## 四、必须查全的几类信息

做资本化盘点时，以下几项漏了就是硬伤：

| 项 | 检查要点 |
|---|---|
| 上市地 | A 股 / H 股 / **A+H 双重上市**都要查，只查一个会漏（如兆威机电） |
| 保荐机构 | 港股招股书封面区分 Sole Sponsor（独家）/ Joint Sponsors（联席），联席要列全 |
| 历史主体 | 合并前的**国泰君安**、**海通证券**做过的项目都要包含，按当时主体名称列示 |
| 辅导券商 | 证监局辅导备案公示可查，不要轻易写"未公开披露" |
| 项目类型 | IPO / 再融资 / 可转债分别标注 |
| 终止项目 | 撤回、终止的也要列，注明时点和原因（若已披露） |
| 投资主体 | 写全称（国泰君安证裕 / 海通开元 / 海通创新证券投资），
不要用母公司名代替；间接持股写清穿透路径 |
| 主体沿革 | 合并、更名、吸收合并要加注释说明 |

**"公开渠道查不到"要先真的查过再说。** 辅导备案、股东穿透、
主流媒体报道往往都能查到，直接写"未公开披露"会被打回。

## 五、复核流程

写完之后必须做一遍独立复核，不是重读，是**逐条回到来源验证**：

1. **抽取**：把全文所有数字和事实性断言列成清单
2. **回源**：逐条打开来源核对数值、年份、口径、机构名
3. **归属核对**：特别检查"某某机构说了什么"—— 张冠李戴是最常见的错误
   （本项目就出现过把新战略咨询的统计误记为 GGII）
4. **交叉核对**：表里的数 vs 正文的数 vs 图里的数，三处必须一致
5. **业务描述核对**：公司主营业务描述要回到年报/招股书的原话确认，
   不要凭公司名猜
6. **处置**：核实不了的**整条删除**，同时记入来源清单的"未能核实事项"页
7. **留痕**：所有修正记入"复核修正记录"页（原表述 / 修正后 / 原因 / 来源）

复核发现的问题不要藏。如实告诉用户改了什么、为什么改。

## 六、数据来源清单（交付物之一）

独立的 Excel 文件，六个页签：

| 页签 | 内容 |
|---|---|
| `00_说明` | 清单用途、编制时间、数据截止日 |
| `01_建议下载的原始文件` | 文件名、机构、类型、URL（超链接）、对应报告的哪一处 |
| `02_逐条数据来源` | 报告位置（章节/表号/图号）、数据内容、来源机构、来源文件、口径、获取日期 |
| `03_口径冲突对照` | 同一指标的不同口径并列、差异原因说明 |
| `04_复核修正记录` | 原表述、修正后表述、修正原因、依据来源 |
| `05_未能核实事项` | 未能核实的内容、已尝试的渠道、处置方式（已从正文删除） |

⚠️ 本环境外部下载常被拦截，**原始文件通常打不了包**。
这时如实说明，只给带 URL 的清单，不要声称已打包。
