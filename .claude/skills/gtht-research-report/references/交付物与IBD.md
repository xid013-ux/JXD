# 交付物与 IBD Tools 衔接

## 一、四份交付物

| # | 文件 | 说明 |
|---|---|---|
| 1 | `XX研究.docx` | 正文报告，可编辑 |
| 2 | `XX研究_图表数据底稿.xlsx` | 报告中所有表、图用到的数据，以及制图数据 |
| 3 | `XX研究_数据来源清单.xlsx` | 见 `数据与来源规范.md` 第六节 |
| 4 | `XX研究_研究提纲memo.docx` | **写作前**产出，供领导确认工作方式和节奏 |

用户可能只要其中一两份，按当次要求给，不要每次都全套推送。

---

## 二、研究提纲 memo 的写法

这份最容易写错，单独说明。

**它是"动笔前的研究方案"，不是"报告的说明书"。** 时态是将来时：
"拟分为……""计划从……取数""预计……完成"。

硬约束：
- **纯文字，不要表格**
- **不超过 2 页**
- 数据来源**只写类别和渠道**，不逐条列（"分为行业统计、公司披露、
  资本市场数据三类，分别来自行业协会与第三方咨询机构、
  招股书与定期报告、Wind 金融数据库"就够了）
- 不写具体数字、不写结论、不做分析
- 六段左右：研究问题 / 章节划分 / 各章要解决什么 / 数据分类与渠道 /
  重点与篇幅分配 / 时间安排

## 三、Excel 底稿体例

用 openpyxl 生成。页签划分参考：

```
00_说明          用途、口径总述、数据截止日
01_制图数据      每张图一块，注明对应图号，可直接选中作图
02_市场规模与出货
03_核心零部件环节
04_整机企业
05_资本化进度
06_关联机构相关
07_标的公司
08_数据来源清单
09_复核说明
```

**格式要求（明确要求过）**：

```python
from openpyxl.styles import Alignment
align = Alignment(horizontal='center', vertical='center', wrap_text=True)
# 表头和数据单元格全部套用，上下左右都居中
```

其他约定：
- 每个数据块上方写清楚它对应报告的哪张表/哪张图
- 每行数据右侧或下方留来源列
- 数字存为**数值型**，不要预先加千分位逗号（留给 IBD Tools 刷）
- 列宽按内容设置，不要出现 `####`
- 冻结首行

## 四、IBD Tools 衔接

### 能做什么、不能做什么

**不能**：IBD Tools 是装在用户电脑上的 Word/Excel 加载项，靠 Word 界面按钮运行。
本环境是没有 Word 的 Linux 容器，够不到用户机器上的插件，**无法调用**。
不要声称调用了它。

**能**：产出"插件友好"的文件，让用户在 Word 里一键美化。这是实际有效的分工：

> **AI 出稿 → 用户在 Word 里用 IBD Tools 定版**

### 插件友好的硬要求

| 要求 | 原因 |
|---|---|
| 表格必须是 Word **原生 table** | 图片、文本框里的表，"表格美颜""列宽调整""行高统一"读不进去 |
| 用**统一命名样式**（Heading 2/3、Normal Indent、表格后说明） | "一键排版"按样式识别，散装直接格式会被打乱 |
| **不用空格、空行、软回车凑版式** | 手工凑的版式会被排版功能破坏 |
| 字体只用**宋体 / 黑体 / Times New Roman** | 插件的字体规范化只认标准字体 |
| 数字存**纯数值**，不预加千分位 | 让"千位分隔"功能直接刷 |
| 图表另附 **Excel 源数据** | 需要在 Word 里重排或改图时有底稿 |
| 目录用 **TOC 域**，不手打 | 插件的目录更新才有效 |

### 建议向用户确认的事

如果用户愿意提供，可以进一步对齐：
- IBD Tools 里常用的表格样式模板叫什么名字
- 部门有没有强制的字体字号规范（可能与本模板不同）
- 页眉页脚、封面页是否由插件统一生成

## 五、必须如实说明的环境限制

每次交付时，涉及以下情况要主动讲清楚，**不要含糊过去**：

1. **LibreOffice 在本环境无法加载 docx** → 无法渲染 PDF、
   无法核对页数和最终视觉效果。页数是估算的，以用户在 Word 里打开为准。
2. **外部下载常被拦截（403）** → 招股书、年报等原始文件打不了包，
   只能提供带 URL 的来源清单。
3. **IBD Tools 无法调用** → 见上。
4. **未能核实的事项** → 已从正文删除，记录在来源清单里，说明尝试过哪些渠道。

如实报告比"看起来完成了"重要。
