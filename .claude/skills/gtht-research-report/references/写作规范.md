# 写作规范（领导定稿取向）

本文件从领导对《中国人形机器人产业链研究》的实际修改中反推得出，
每条规则后面标注了它对应的真实改动，便于理解边界。

---

## 一、总取向

**报告是信息载体，不是分析作品。**

领导定稿版比初稿短、比初稿"平"：删掉了推论性段落和不确定标注，
加进了可查证的人物与公司事实。他要的是一份**对外能拿出去的中性资料**，
读者拿到能知道"这个行业有谁、什么来路、进展到哪一步"，
而不是"作者怎么看这件事"。

判断不是不重要，是**不落在这份纸上**。

---

## 二、六条硬规则

### 规则 1：不写归纳性小结

**删。** 领导整节删掉了"6.7 资本化特征小结"（标题 + 五条特征归纳 + 对标的的启示两段）。

禁止出现的段落类型：
- "本章特征可归纳为以下五点……"
- "对我们的启示是……"
- "综合来看，该环节呈现出……的趋势"
- 章末的"小结""总结""几点判断"

**替代做法**：把事实按逻辑顺序摆好，让读者自己得出结论。
必须给方向性判断时，压缩成一两句放在段落内部，不单独成节、不加小标题。

**例外**：最后一章的"初步判断"是题目要求的部分，可以写，但要克制、
只写有事实支撑的方向，不展开论证。

### 规则 2：不确定的内容删掉，不标注

**删。** 领导删掉了表格里标"（待核实）"的整行，也删掉了正文里
"以 Wind 口径列示，未从公开渠道核到发行时的保荐主体名称，建议以招股说明书封面复核"这条注释。

禁止出现的措辞：
- （待核实）（存疑）（未经核实）
- "建议以……复核""有待进一步确认"
- "据不完全统计，可能存在遗漏"

**替代做法**：
- 能核实 → 核实后写确定的
- 核不出来 → **整条删掉**，另在数据来源清单的"未能核实事项"页里记录，
  正文不体现
- 确实必须提及但口径有差异 → 用**并列陈述**替代不确定标注，
  例如"新战略咨询口径为 2 万台，GGII 口径为 1.8 万台"

### 规则 3：正文不留内部痕迹

**删。** 领导删掉了"也是本次拜访标的可以直接对接的下游客户资源"、
"鉴于其对无锡巨蟹的直接业务相关性，本节从……六个维度展开"、
"、也与本次拜访最直接相关的"等句子。

禁止出现在行业章节和公司章节里的表述：
- "本次拜访""此次调研""标的公司"
- "对我司/对本项目的意义"
- "可对接的客户资源""潜在合作机会"
- "本节从 X 个维度展开"这类写作说明

**替代做法**：拜访相关的内容**全部集中到最后一章**（如"八、XX 的产业链定位与拜访关注要点"），
行业和公司章节保持中性叙述。领导保留了这一整章，说明他反对的不是拜访视角本身，
而是**把它撒进行业分析里**。

⚠️ 删除内部语时注意**句子完整性**。领导删"、也与本次拜访最直接相关的"之后，
原句变成"这是智元区别于多数同行一项特征"，掉了个"的"。删完要重读整句。

### 规则 4：人和公司的事实 > 交易参数

**加。** 领导在公司章节加了一张 9 人合伙人背景表
（姓名 / 目前职务 / 主要教育·职业背景），内容全是硬履历，没有一句评价。

**删。** 领导删掉了整段发行细节：审核天数、发行价、发行后市值、募资额、
市盈率、战略配售名单、与招股阶段底价的对照。

优先级排序：
1. **谁在做**：创始团队、核心高管履历、组织架构、股东背景
2. **做什么**：产品线、技术路线、供应链、客户
3. **做到哪了**：出货量、收入、产能、订单
4. **资本化状态**：上市/在审/辅导，保荐机构，轮次和投资方
5. **交易参数**：发行价、估值、市盈率、配售明细 ← 除非题目就是它，否则不写

写人物背景表的体例：
- 只写可查证的教育背景、任职经历、代表性成果
- 不写"技术功底深厚""业内知名"这类评价词
- 分号断句，一格一人，长度控制在 2–3 句

### 规则 5：沿用他的用词，不做"改进"

**改回。** 我把"Wind 整理成果 / Wind 金融数据库整理成果"统一改成"Wind 数据库"，
他 9 处全部改了回去；连一处语法杂糅（"本章基于 Wind 数据库数据源的基础上"）
也恢复了原样。

固定用词表：

| 场景 | 用 | 不要用 |
|---|---|---|
| Wind 取数 | **Wind 整理成果** / Wind 金融数据库整理成果 | Wind 数据库、Wind 数据 |
| 本部门署名 | 国泰海通投资银行部整理 | 国泰海通证券、本部门 |
| 数据出处引导 | 数据来源：/ 资料来源： | 来源：、Source: |
| 合并前主体 | 国泰君安 / 海通证券（需明确区分） | 统称国泰海通 |

关键在"**整理成果**"这个词，不在"数据库"。他两种长短写法都用，但一定带"整理成果"。

**原则**：领导已经写定的措辞不动。语法上的小瑕疵不值得为了"更正确"去改，
改了会被改回来，是纯损耗。真要提，口头提。

### 规则 6：不做券商自我宣传

不写排名、承销规模、市场份额、"业内领先"这类内容。
涉及本机构时只陈述客观关系：保荐了谁、投了谁、辅导了谁。

## 三、文风

- **陈述句为主**，少用设问、排比、感叹
- **不用形容词堆砌**："快速增长"可以，"迅猛爆发式增长"不行
- **数字紧跟单位和年份**："2025 年出货约 2 万台"，不写"出货约 2 万台（2025）"
- **段落长度** 3–6 句，一段一个意思；不写只有一句话的段落
- **不用第一人称**：不写"我们认为""笔者以为"
- **不加免责声明**：正文里不出现"本报告仅供内部参考"之类的整段声明
- **中文标点**：全角引号 `“”`、顿号、书名号；ASCII 直引号 `"` 一律不要出现
- **专业术语首次出现给中文全称**，缩写放括号里：一体化动力关节模组（QDD）

---

## 四、区分容易混淆的概念

这几组在投行语境里必须分清，混了是硬伤：

| 不要混 | 说明 |
|---|---|
| 券商系**股东** vs **保荐**关系 | 投了钱 ≠ 做了保荐，两件事分表列示 |
| **IPO** vs **再融资** vs **可转债** | 分别标注项目类型，不笼统写"承做" |
| **主保荐/独家保荐** vs **联席保荐** | 港股招股书封面写 Sole Sponsor 就是独家 |
| **辅导备案** vs **已受理/在审** vs **已递表** | 三个不同阶段，进度表里不得合并 |
| **仅完成股改** vs **已辅导备案** | 前者未必有中介机构，不要臆测 |
| 合并前的**国泰君安** / **海通证券** | 历史项目要按当时主体名称列示 |
| 母公司 vs 投资平台 | 国泰君安证裕 / 海通开元 / 恒旭资本等，主体名称写全 |

## 五、定稿检查清单

出稿前逐条过：

**内容**
- [ ] 没有"小结/启示/特征归纳"类段落（拜访专章的"初步判断"除外）
- [ ] 没有"待核实/存疑/建议复核"标注，存疑内容已删除并转入来源清单
- [ ] 行业章节和公司章节里没有"本次拜访""对我司"等内部语
- [ ] 删除内部语后的句子重读过，语法完整
- [ ] 人物、组织、产品线等事实性内容充分；交易参数没有喧宾夺主
- [ ] 没有券商自我宣传内容
- [ ] 股东关系 / 保荐关系 / IPO / 再融资分表列示，未混淆
- [ ] 合并前主体（国泰君安、海通证券）按历史名称列示

**数据**
- [ ] 每个数字都有来源，每个观点都能溯源
- [ ] 口径不同的数据并列呈现，未平均、未合并
- [ ] 年份、单位、口径三者齐全
- [ ] 上市状态完整（A 股 / H 股 / A+H 都要查全）
- [ ] 表格与正文的数字一致，图与正文的结论一致

**文字**
- [ ] 无错别字、无病句
- [ ] 无 ASCII 直引号（跑 `check_report.py` 检）
- [ ] 用词符合固定用词表
- [ ] 前后表述一致（同一家公司名称、同一指标口径全文统一）

**格式**
- [ ] 所有表、图都有编号和标题，编号连续无跳号
- [ ] 所有表、图下方都有"数据来源/资料来源"注，七号字居中
- [ ] 目录已生成且层级正确
- [ ] 通过 XSD 校验
