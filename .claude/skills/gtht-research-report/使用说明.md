# 怎么装、怎么用（小白版）

---

## 一、skill 到底是个什么东西

**一句话：skill 就是一个文件夹，里面装着"写这类报告的规矩"。**

你把这个文件夹放到指定位置，以后每次让 Claude 写行业研究报告，
它会**自动**先读一遍这些规矩，再动手写。

不用你每次重复交代"数据要有出处""不要写小结""来源注用七号字"——
这些都写在文件夹里了。

打个比方：以前是你每次口头教一遍新来的实习生；
现在是把规矩印成一本手册放在他桌上，他每次干活前自己翻。

---

## 二、装到哪里

有两个位置，**推荐第二个**。

### 位置 A：只在某一个项目里用

```
你的项目文件夹\.claude\skills\gtht-research-report\
```

只有在这个项目里工作时才生效。

### 位置 B：所有项目都能用 ✅ 推荐

**Windows：**
```
C:\Users\你的用户名\.claude\skills\gtht-research-report\
```

**Mac：**
```
/Users/你的用户名/.claude/skills/gtht-research-report/
```

放这里，不管你在哪个文件夹里开 Claude，它都能用。

## 三、安装步骤（Windows）

### 第 1 步：解压

把 `GTHT内部研究报告skills.zip` 解压出来，
会得到一个叫 `gtht-research-report` 的文件夹。

打开看一眼，里面应该长这样：

```
gtht-research-report\
├── SKILL.md
├── 使用说明.md
├── references\      （5 个 .md 文件）
├── assets\          （模板 docx + 2 个 .py）
└── scripts\         （2 个 .py）
```

⚠️ 注意：解压后有的软件会多套一层文件夹，
变成 `gtht-research-report\gtht-research-report\SKILL.md`。
**要的是直接包含 `SKILL.md` 的那一层**，多余的外层去掉。

### 第 2 步：找到目标位置

按 `Win + R`，输入下面这行，回车：

```
%USERPROFILE%\.claude
```

- 如果打开了一个文件夹 → 很好，继续
- 如果提示找不到 → 说明 `.claude` 文件夹还没建。
  在 `C:\Users\你的用户名\` 下**新建文件夹**，命名 `.claude`
  （注意前面有个点。Windows 可能不让你建以点开头的文件夹，
  这时候名字写成 `.claude.`，末尾多一个点，回车后系统会自动去掉）

### 第 3 步：建 skills 文件夹

在 `.claude` 里面新建一个文件夹，命名 `skills`（全小写）。

### 第 4 步：拷进去

把第 1 步解压出来的 `gtht-research-report` 整个文件夹，
拖进 `skills` 里。

最终路径应该是：

```
C:\Users\你的用户名\.claude\skills\gtht-research-report\SKILL.md
```

**能在这个路径下看到 SKILL.md，就算装好了。**

### 第 5 步：重启 Claude

关掉 Claude 再打开。skill 是启动时加载的，不重启看不到。

## 四、怎么确认装好了

打开 Claude，输入：

```
/
```

会弹出一个列表，往下翻，看有没有 `gtht-research-report`。
有 → 装好了。

或者直接问它：

```
你现在能用 GTHT 内部研究报告这个 skill 吗？
```

## 五、怎么用

### 用法 1：直接说话（最常用）

**不需要输入任何命令**，正常提要求就行：

```
帮我写一份固态电池产业链的研究报告，重点看电解质环节，
下周三要给领导看。
```

Claude 看到"研究报告""产业链"这些词，会自动去读这个 skill，
然后按规矩来。你会发现它不用你提醒就知道要先出提纲、
数据要标口径、来源注要用七号字。

### 用法 2：明确点名（想确保用上时）

```
/gtht-research-report
```

或者说：

```
用 GTHT 内部研究报告的规范，帮我写一份 XX 行业的研究。
```

## 六、怎么提要求，效果最好

**说清楚这四件事，剩下的它知道：**

| 要说的 | 例子 |
|---|---|
| ① 写什么行业 | 固态电池产业链 |
| ② 重点看哪一环 | 重点是电解质和设备环节，其他简写 |
| ③ 有没有具体标的 | 要去拜访 XX 公司，他们做硫化物电解质 |
| ④ 要哪几份东西 | 只要 Word 正文就行 / 四份都要 |

**完整示范：**

```
帮我写一份固态电池产业链研究报告。
重点看电解质和专用设备两个环节，其他环节简单带过。
下周要去拜访某家做硫化物电解质的公司，报告要能支撑这次拜访。
先给我提纲，我给领导过一遍再写正文。
```

### 不用再说的话（skill 里已经有了）

以下这些**不用每次重复**，省口舌：

- ~~"数据要有出处"~~
- ~~"来源注用七号字居中"~~
- ~~"不要写小结和启示"~~
- ~~"字体格式按模板来"~~
- ~~"给我 Excel 底稿和来源清单"~~
- ~~"多列事实少列观点"~~

## 七、正常的工作节奏

```
你提需求
   ↓
Claude 先给提纲（2 页以内，纯文字）  ← 这里拿给领导看
   ↓
你说"可以，开始写"
   ↓
Claude 一章一章写，每章标出要核实的点
   ↓
出四份文件：Word 正文 + Excel 底稿 + 来源清单 + 提纲
   ↓
你在 Word 里用 IBD Tools 一键美化
   ↓
定稿
```

**别跳过提纲那步。** 领导认的是工作方式，提纲阶段调整成本最低。

## 八、自检怎么用

报告写完，可以让 Claude 跑一遍自动检查：

```
帮我用 skill 里的 check_report.py 检查一下这份报告
```

它会查这些：

- 有没有"待核实""建议复核"（老板会删的）
- 有没有"业内认为""有望"（新要求：多列事实少列观点）
- 有没有"本次拜访"跑到行业章节里
- 来源注是不是七号字、是不是居中、是不是双出处
- 表和图的编号连不连续
- 有没有 ASCII 直引号混进来

查出来的分**错误**和**提醒**两档：
错误必须改，提醒自己判断。

## 九、常见问题

**Q：装了没反应？**
按顺序排查：
1. 路径对不对 —— 必须能看到 `...\.claude\skills\gtht-research-report\SKILL.md`
2. 是不是多套了一层文件夹
3. 重启 Claude 了吗
4. `skills` 是不是写成了 `skill`（要有 s）

**Q：文件夹建不出来，Windows 说"必须键入文件名"？**
因为名字以点开头。建的时候在末尾**多打一个点**：`.claude.`
回车后系统会自动去掉末尾那个点，变成 `.claude`。

**Q：它写出来的东西还是不对？**
直接告诉它哪不对。改完之后跟一句：

```
把这条也加进 skill 里，以后别再犯。
```

这个 skill 是活的，越用越准。

**Q：换电脑了怎么办？**
把 `gtht-research-report` 文件夹拷过去，放到同样位置就行。
建议在网盘或者 Git 上留一份。

**Q：能给同事用吗？**
能。整个文件夹发给他，让他按上面步骤放到自己的
`.claude\skills\` 里。

## 十、以后怎么维护

**领导每次提新要求，就加进去。** 对 Claude 说：

```
领导说以后 XXX 要 YYY，加到 GTHT 那个 skill 里。
```

它会自己找到对应的文件改。这样规矩只会越攒越全，
不会因为你换了个对话就忘了。

改完记得把文件夹重新备份一份。
